Character Design & Consistency

Project Overview

This project demonstrates the use of AI prompt engineering to create and maintain a consistent fictional character across multiple visual scenarios.

The goal was to establish a detailed character reference and then adapt the same character across different outfits, poses, expressions, environments, actions, and camera perspectives while preserving recognizable identity.

Creative Direction

Subject: Fictional young African woman
Age: Late 20s
Visual Style: Professional, contemporary, photorealistic
Format: 16:9

Character Reference

The character was defined with consistent visual characteristics, including:

- Deep dark-brown skin
- Oval face
- Defined cheekbones
- Almond-shaped dark-brown eyes
- Naturally full lips
- Defined eyebrows
- Small distinctive beauty mark below the left eye
- Medium height
- Balanced proportions
- Shoulder-length natural black twists
- Small gold hoop earrings
- Cream blouse

Prompt Engineering Approach

The character reference was established first and then reused as the foundation for subsequent prompts.

Each prompt maintained the core identity while changing selected visual variables such as:

- Clothing
- Pose
- Facial expression
- Environment
- Activity
- Camera angle
- Perspective
- Composition

This approach helped maintain character continuity while allowing creative variation.

Visual Variations

1. Character Master Reference

The first image established the character's facial features, hairstyle, skin tone, proportions, clothing, and overall appearance.

2. Different Outfit

The same character was placed in a different outfit while maintaining her recognizable facial identity, hairstyle, skin tone, and proportions.

3. Different Pose & Expression

The character was presented with a different pose and facial expression while preserving her established identity.

4. Different Environment

The character was placed in a new environment while maintaining the same physical characteristics and overall appearance.

5. Character in Action

The character was shown performing an activity, requiring the prompt to maintain her identity while introducing movement and environmental interaction.

6. Different Perspectives

The character was presented from different camera perspectives and angles while maintaining consistent facial and physical characteristics.

Key Prompt Engineering Techniques

Character Anchoring

Important physical characteristics were repeatedly specified to reinforce character identity.

Controlled Variation

Only selected attributes were changed between prompts, allowing creative flexibility without unnecessarily changing the character.

Visual Consistency

Skin tone, facial structure, hairstyle, body proportions, and other defining characteristics were maintained across the series.

Camera Direction

Prompts included camera perspective, framing, composition, and viewing angle to create visual variety.

Environmental Adaptation

The character was placed in different environments while preserving her core visual identity.
